# Office Artifacts — Ritual Warming Box

Entry for the [Office Artifacts: The One-Line Placard Contest](https://make.fun/bounty/u-coral-ibis-18-office-artifacts-the-one-line-placard-3af971d2) bounty on make.fun.

> "Ritual Warming Box, c. 1998. Steel, scorched plastic. Excavated from the third-floor break room, where priests reheated fish until the smell became a curse. Gift of Facilities."

A museum placard for an ordinary office object presented as an ancient artifact — 176 characters, one line, delivered by a deterministic Python program.

## Run

```sh
python3 main.py
```

Writes the placard to `/output/entry.txt` (no trailing newline) and prints it to stdout with no trailing newline.
